# Python Game Memory Manipulation Example

This example demonstrates the core concept of memory manipulation, a fundamental aspect of reverse engineering. It simulates a simple game where a 'cheat' intervenes to modify in-memory variables like player health and score, illustrating how live program state can be altered to change behavior. This mimics the basic idea behind game cheating or understanding program flow by observing and modifying runtime values.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
